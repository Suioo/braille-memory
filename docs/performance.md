# 动画与性能

## 帧率探针（2.13.0）

- 打开：设置 → 关于 → 帧率探针（调试）。屏幕左上角出现浮层：`60 fps · 最差 16.7 ms · 掉帧 0`；掉帧超过 10% 或出现长帧（> 50 ms）时变红，有掉帧变黄。
- 「复制报告」：复制一份文字报告（总帧数、刷新间隔估计、P95 / P99 / 最差、掉帧 / 长帧 / 冻结计数、按场景归类、最差的几帧、long-animation-frame 记录）。
- **场景**：页面名（learn / practice / round / ruleround / me …），以及临时标签：`转场`（换页后 0.5 秒）、`答对动画`（答对 / 过关后 1.3 秒）。哪个场景掉帧一目了然。
- 统计逻辑在 `src/core/frameprobe.js`（纯逻辑，有测试）：刷新间隔取帧间隔的中位数（60 / 90 / 120 Hz 自动识别），掉帧 = 帧间隔 > 1.5 × 刷新间隔，长帧 > 50 ms，冻结 > 200 ms；超过 1 秒的间隔（后台、休眠）不算。
- 关闭后 rAF 循环、定时器和 PerformanceObserver 全部停止，无任何开销。截图 / e2e 模式不启用。

## 2.13.0 已做的性能修复

| 项 | 做法 |
|---|---|
| 玻璃模糊 | 只留 4 处固定大面；其余半透明填充 + 高光边；半径 22 px、饱和度 190%；换页动画期间暂停模糊 |
| 进度条 | `transform: scaleX`（合成器线程），不再动画 `width` |
| 动画类残留 | 换页动画结束（animationend + 700 ms 兜底）后摘掉 `anim-*` 类 |

## 暂未改、等探针数据再定的项

- 滑动指示块：位置由 JS 弹簧每帧写 `left / right`（绝对定位的叶子元素，不引起其他元素重排，代价主要是重绘）。改成 transform 会让圆角随 `scaleX` 变形，要重做「拉伸跟随」，先看数据再决定。
- 翻卡抬起的 `box-shadow` 关键帧：卡片在 3D 上下文里（`preserve-3d`），把阴影挪到伪元素会影响正反面的绘制顺序，风险大于收益，先看翻卡场景是否掉帧。
- 长句盲文串（上百方）的一次性渲染：看 `ruleround` 揭晓时的长帧再决定是否分帧渲染。
