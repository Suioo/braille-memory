# 盲文记忆 — 设计说明

> Windows 桌面版，Electron（纯 HTML/CSS/JS，无打包器、无框架、无额外 npm 依赖）。
> 本文不含任何具体符号的点位；点位只来自 `data/braille_table.csv`。
> **视觉方向（2026-10-17 用户变更）**：由纯黑白改为 **Material Design 3（Material You）**，纯 CSS 实现。

## 1. 产品目标

- 帮明眼的特教学习者记住《国家通用盲文方案》（GF 0019—2018）中汉语现行盲文的点位。
- 学（卡片）→ 练（点点位 / 选符号）→ 复习（按薄弱加权）→ 错题 → 分课闯关。
- 柔和的 M3 配色（不刺眼）、圆点意象；几乎没有文字；键盘可完成全部操作。
- 从零开始，不导入旧版（Godot）记录。

## 2. 页面清单与跳转

底部导航 4 个标签页（带导航栏），其余为全屏页（顶部应用栏带返回）。

| 页面 | 类型 | 进入 | 离开 |
|---|---|---|---|
| 学习 `learn` | 标签 | 启动默认 / 导航栏 | 导航栏 |
| 练习 `practice` | 标签 | 导航栏；答题/结果页返回 | 开始 → 答题；复习 / 错题 → 答题 |
| 闯关 `course` | 标签 | 导航栏；单课/课结果返回 | 点已解锁的课 → 单课 |
| 我的 `me` | 标签 | 导航栏 | 导航栏 |
| 答题 `round`（practice / review / wrong） | 全屏 | 练习页 | 答完 → 结果；← / Esc → 练习 |
| 结果 `result` | 全屏 | 一轮结束 | 再来 → 答题；返回 → 练习 |
| 单课 `lesson`（学 → 练 → 测） | 全屏 | 闯关 | 测完 → 课结果；← / Esc → 闯关 |
| 课结果 `lessonResult` | 全屏 | 单课测完 | 下一课 / 重做 / 返回闯关 |

```
[学习] [练习] [闯关] [我的]   ← 底部导航
          │        │
          ├─ round ─ result ─(再来)→ round
          │        └─ lesson(学→练→测) ─ lessonResult ─(下一课/重做)→ lesson
```

## 3. 文字线框

**学习（标签）**
```
│ 学习                       i / n │  顶部应用栏
│ [✓全部 52][类别 n][类别 n]…      │  筛选芯片（类别来自 CSV）
│          [✓阅读 | 镜像]           │  分段按钮
│ ╭──────────────────────────────╮ │
│ │            符号               │ │  卡片（surface-container-high，圆角 28）
│ │   背面：符号 + 盲文方 + 数字   │ │  翻面 = 3D 翻转
│ ╰──────────────────────────────╯ │
│  (‹)        [⟳ 翻面]        (›)  │
│ ─────────────────────────────── │
│  学习    练习    闯关    我的     │  底部导航（选中项有胶囊指示器）
```

**练习（标签）**
```
│ 练习                              │
│ [✓全部][类别]…   [✓阅读 | 镜像]   │
│ ╭ 练习  52            [▶ 开始] ╮ │  主卡片（primary-container）+ 主按钮
│ ╭ ⟲ 复习   n ╮ ╭ ⊕ 错题   k ╮    │  k = 0 时禁用
│ 题型 [点位|选符|✓混合]            │
│ 题量 [✓10|20]                     │
```

**答题 · 点点位**
```
│ ←  练习 i / N            ✕ w  ⇋ │  ⇋ = 镜像切换
│ ━━━━━━━━──────────────────────• │  线性进度条
│              符号                 │
│        ╭ (1) (4) ╮               │  盲文方卡片
│        │ (2) (5) │               │  揭晓：✓ / + / ✕ 角标
│        ╰ (3) (6) ╯               │
│   (✕)  ⊕ 漏数  ⊗ 多数 │ 正确 数字 │  仅答错时
│            [ 提交 / 继续 ]        │
```

**答题 · 选符号**：上方静态盲文方卡片，下方 2×2 选项卡片（左上角键位 1–4）；答后正确项 ✓（primary-container），选错项 ✕（error-container + 虚线框）。

**结果**：结果卡（✓/✕、正确率大数字、题数 / 用时 / 均时）、答错符号的辅助芯片、`[返回] [⟲ 再来]`。

**闯关（标签）**：顶部右侧总星数；过关进度条；按 CSV 类别分组的课卡（课号、三个星点、符号预览）；
当前可做的课 = primary-container；锁定课 = 低层容器 + 锁形。

**单课**：顶栏 `← 类别 k  ⇋`；下方步骤点 `(学)(练)(测)` 与计时（仅测且开启计时）；
学 = 学习卡 + `(‹) [翻面] [继续]`；练 = 点点位 + `[💡提示] [提交]`，每符号两个小点显示干净答对进度；
答错 → 揭晓 → 继续 → 该符号学习卡（背面）→ 继续；测 = 盲写（不显示编号），进度条。

**课结果**：三个大星点、正确率、题数、均时；`[返回] [重做] [下一课]`。

**我的（标签）**：统计卡（待加强 / 过关 / 星）；设置列表：主题（系统/浅色/深色）、颜色（4 个种子色圆点）、
视角（阅读/镜像）、题量（10/20）、题型（点位/选符/混合）、自动下题（开关）、计时（开关）、
记录（`导出` `导入`，导入过后多一个 `撤销`；选好文件并校验通过后，下方出现一行「覆盖？导入 N 项，跳过 M 项」`[取消] [覆盖]`）、
清除进度（`清除` → 行内 `[取消] [确认]`）。

## 4. 交互与键盘

| 键 | 作用 |
|---|---|
| 1–6 | 点点位题：按**点位编号**切换该点（与镜像后的屏幕位置无关） |
| 1–4 | 选符号题：选第 1–4 个选项 |
| Enter | 提交 / 继续；学习卡上 = 翻面（单课学习阶段 = 继续） |
| 空格 | 学习卡翻面 |
| ← / → | 学习卡上一张 / 下一张；在芯片、分段按钮、导航栏、课卡、选项中移动焦点 |
| Esc | 全屏页返回上一级；「我的」中取消清除确认 / 取消覆盖导入 |
| Tab | 在所有控件间移动；焦点环 3 px primary 实线 |

- 焦点在普通按钮上时 Enter/空格只触发该按钮（不重复触发）；焦点在点位上时 Enter = 提交。
- 新题出现后 150 ms 内的输入忽略（防误触）。
- 答对：自动下一题 0.9 s（镜像 1.5 s）；可在设置关闭。答错：停留到用户按「继续」。
- 控件点击区 ≥ 44 px（芯片视觉高 40 px，点击区向上下各扩 2 px）；全部控件有 `aria-label` / 可见文字；
  `aria-live` 区域播报题目、对错、漏点/多点。

## 5. 动效清单（M3 缓动）

缓动：emphasized `cubic-bezier(.2,0,0,1)`、emphasized-decelerate `cubic-bezier(.05,.7,.1,1)`、
standard-decelerate `cubic-bezier(0,0,0,1)`。

| 动效 | 触发 | 时长 | 缓动 | 作用 | 减少动态时 |
|---|---|---|---|---|---|
| 状态层 | 悬停 / 按下 / 键盘焦点 | 150 ms | standard | 叠加 8% / 12% 的内容色 + 按下缩至 0.97（不是水波） | 瞬时 |
| 点位凸起回弹 | 切换点位 | 200 ms | emph-decel，0.86 → 1.06 → 1 | 按下凸点的触感 | 瞬时 |
| 学习卡翻面 | 翻面 | 350 ms | emphasized，rotateY 180° | 正反面关系 | 瞬时 |
| 前进页（共享轴 X） | 进入全屏页 | 300 ms | emph-decel，+30 px → 0 + 淡入 | 层级加深 | 瞬时 |
| 返回页 | 返回标签页 | 300 ms | emph-decel，−30 px → 0 | 层级返回 | 瞬时 |
| 标签切换（淡入穿透） | 导航栏 | 300 ms | emph-decel，0.96 → 1 + 淡入 | 同级切换 | 瞬时 |
| 新题 / 新卡滑入 | 下一题 / 下一张 | 250 ms | emph-decel，+30 px → 0 | 内容更换 | 瞬时 |
| 勾号描边 | 答对 | 300 ms | std-decel | 肯定反馈 | 直接显示 |
| 漏点虚线圈依次出现 | 答错揭晓 | 每个 200 ms，错开 40 ms | emph-decel，0.7 → 1 | 引导看漏点 | 同时出现 |
| 角标淡入 | 揭晓 | 200 ms | std-decel | 命中/多点标记 | 瞬时 |
| 导航指示器 | 切换标签 | 250 ms | emph-decel，横向展开 | 当前位置 | 瞬时 |
| 开关滑块 | 切换 | 250 ms | emphasized | 状态变化 | 瞬时 |
| 进度条 | 答题后 | 300 ms | emphasized | 进度 | 瞬时 |
| 课结果星点 | 进入课结果 | 200 ms，错开 80 ms | emph-decel | 获得星 | 瞬时 |

不使用：水滴/气泡/水波圆、抖动、闪烁、循环动画、渐变、毛玻璃、厚重阴影。

## 6. 视觉规范（Material 3）

- **配色**：`src/core/palette.js` 由种子色生成色调板（tone = CIELAB L*；色相/彩度用 CIELAB 近似 M3 的 HCT），
  按 M3 Tonal Spot 规则取角色：primary / on-primary / primary-container / on-primary-container / secondary(-container) /
  tertiary(-container) / error(-container) / surface / surface-container-lowest…highest / on-surface / on-surface-variant /
  outline / outline-variant。浅色 surface = tone 98（带色调的米白），深色 surface = tone 6（约 #0D1418），文字非纯黑/纯白。
  种子：青蓝 `#2F6F8F`（默认）、靛蓝 `#4F5BB5`、松绿 `#3F7D4E`、陶土 `#B5603A`，在「我的 → 颜色」切换。
  主题：跟随系统 / 浅色 / 深色。实测对比度见 `docs/contrast.md`（正文 ≥ 4.5:1，控件 ≥ 3:1，全部达到）。
- **outline-variant 例外**：只有约 1.4–1.5:1，只用于装饰分隔线；空点细圈、芯片/分段按钮边框、禁用文字用 `outline`（≥ 3:1）。
- **字体**：`"Microsoft YaHei UI", "Segoe UI", sans-serif`；只用真实字重 400 / 700（`font-synthesis: none`）；关闭 LCD 亚像素抗锯齿。
- **字号（M3 字阶）**：display 45/36、headline 28/24、title 22/16/14、body 16/14、label 14/12；符号按宽度三档（随窗口高度收缩）。
- **形状**：按钮 / 分段按钮全胶囊；芯片 8 px；卡片 16–28 px；导航指示器 16 px。
- **层次**：用 surface-container 各级（tonal elevation），不用厚阴影。
- **组件**：顶部应用栏（64 px）、底部导航栏（80 px，图标 + 2 字标签）、填充 / 色调 / 描边 / 文字按钮、主操作大按钮（56 px）、
  筛选芯片（选中带 ✓）、分段按钮（选中带 ✓）、开关（带 ✓ 滑块）、线性进度条、图标按钮（可切换）。图标为自绘内联 SVG。
- **盲文方**：2×3 网格放在 surface-container-high 卡片上；默认左列 1-2-3、右列 4-5-6；镜像时左列 4-5-6、右列 1-2-3（编号不变）。
  - 凸起点 = primary 实心圆；无点 = outline 细圈。
  - 揭晓（形状为主、颜色为辅）：命中 = primary 实心 + ✓ 角标（primary-container）；
    漏点 = tertiary 虚线圈 + 「+」角标（tertiary-container）；
    多点 = error-container 实心 + 粗 error 外圈 + ✕ 角标（error-container）。
- **迷你预览点图**：每次向用户展示某符号的点位时，旁边再放一个无编号、无角标、像真实盲文的小方格：
  凸起 = on-surface 实心小圆，空位 = 很淡的细圈（仅定位）；点径 : 圆心距 ≈ 1.5 : 2.5（间隙 = 0.67 × 点径），点径 `clamp(12px, 2vw, 16px)`
  （矮窗口 11 px，芯片内 6 px）；跟随阅读/镜像；读屏名称列出凸起点编号。
  出现位置：学习卡背面（符号左侧）、单课学习卡与答错后的复习卡、选符号题题面（大方格左侧）；
  点点位题与单课练/测**只在揭晓后**显示（随揭晓 200 ms 淡入，减少动态时瞬时），之前显示会泄露答案；结果页 / 课结果的答错符号芯片。
- **星**：3 个圆点，primary 实心 = 获得，outline 空心 = 未获得。
- **应用图标**：M3 超椭圆底（primary-container）+ 居中 2×3 盲文方（primary 实心点、淡色空圈），
  点位取 CSV 第一条数据行（运行时读取，纯装饰），由 `tools/make-icon.js` 生成。

## 7. 数据与存档

- **字表**：`data/braille_table.csv`（id, symbol, dots, source, category）。主进程读入并校验
  （列齐全、id 唯一、dots 为 1–6 不重复数字、点位组合不重复），经 IPC 传给页面；出错时显示错误态。类别名一律从 category 列读取。
- **配置**：`data/config.json`（每课符号数、选项数、计分、题量、自动下题时长、防误触、闯关阈值），主进程合并到默认值后下发。
- **存档**：`app.getPath('userData')/progress.json`；原子写入（先写 `.tmp` 再改名）；
  读到损坏文件先改名为 `.corrupt`（已有则加时间戳）备份，再从空进度开始。
  ```
  { version: 2,
    settings: { theme, seed, mirror, scope, roundLength, autoNext, timing, qtype },
    symbols:  { "<id>": { sig: "符号|点位", score, right, wrong } },
    lessons:  { "<类别>#<课号>": { sig: "id,id,…", stars, bestAcc, bestAvgSec, plays } },
    ext:      { symbols: { "<id>": { sig: "符号|各方点位", score, right, wrong } } } }   // 扩展符号，单独存放
  ```
  `sig` 与当前 CSV 不符的记录在读入时丢弃（导入记录文件时同样处理，并计入「跳过」）。清除进度保留设置。
- 版本 1 → 2：读入 v1 时 symbols / lessons / settings 逐字段原样保留，只新增空的 `ext`；导入的 v1 导出文件同样迁移。扩展表缺失或有错时，已有 `ext` 记录原样保留，不因此丢档。课程解锁：已有星星的课永远解锁（字表增补后新课插在中间也不会把旧课重新锁住）。
- 导入前把当前记录备份到单独位置（Electron：`progress.backup.json`；Web / 安卓：独立 localStorage 键），供「撤销」使用。
- 截图（`--shot` / `--shot-all`）用临时数据目录且不写盘；测试只用系统临时目录；冒烟（`--e2e`）必须给 `--user-data`。

## 8. 规则

- **分数**：每符号 score 0..8；答对 −1（下限 0），答错 +2（上限 8）。待加强 = score > 0。
- **范围**：全部 / 某类别（从 CSV 读）；作用于学习、练习、复习、错题。
- **学**：卡片自己翻，编号可见，支持镜像，不计分。
- **练**：看符号点点位 / 看点位选符号 / 混合；选符号 4 个选项，点位互不相同（范围内不够时从全表补）。
- **复习**：范围内按 1 + score 加权抽题，不紧挨重复。
- **错题**：只出 score > 0 的符号；没有待加强时立即结束。
- **分课闯关**：
  - 按 CSV 类别（首次出现顺序）与行序分课：每类 L = ceil(c/5) 课均分（余数给前面的课）。
  - 每课：学（逐张卡）→ 练（每符号干净答对 2 次；答错先揭晓、再看该符号学习卡，清零并隔 2 个再出现；
    「提示」显示正确点位数字，用后答对不算干净）→ 测（盲写 = 隐藏编号，每符号 2 次，打乱且不相邻，正向计时，计时可关）。
  - 课内「练」不写分数；「测」只记错：答错 wrong + 1 且 score + 2（上限 8），答对不写。
  - 计时：每题从出现到提交；揭晓等待与窗口失焦/隐藏期间不计。
  - 评星（`data/config.json` 可配）：过关 ≥ 80% 且均时 ≤ 12 s；2 星 ≥ 90% 且 ≤ 9 s；3 星 100% 且 ≤ 6 s；计时关闭时只看正确率。
  - 顺序解锁（前一课 ≥ 1 星），可重做，星只升不降。

## 9. 验收标准

1. `npx electron .` 在 D:\braille-memory 启动无报错，窗口 720×960、可缩放、最小 480×640。
2. 代码与文档不含具体符号的点位；界面所有点位、类别名来自 CSV（`data.test.js` 全表解析无错误、无重复点位）。
3. 盲文方默认左 1-2-3 右 4-5-6；镜像时左右列互换且编号不变（`cell.test.js`，截图 `learn-mirror`、`practice-wrong-mirror`）。
4. 键 1–6 按编号切换点位（镜像下同样按编号），Enter 提交/继续，Esc 返回；选符号题 1–4 可选。
5. 揭晓态：命中 ✓、漏点虚线 +、多点 ✕，只看形状也能区分；颜色为辅。
6. 计分：答对 −1 下限 0、答错 +2 上限 8；测验只记错（`progress.test.js`）。
7. 选符号题 4 个选项点位互不相同（`pick.test.js`、`round.test.js`）。
8. 分课：每类 ceil(c/5) 课均分；顺序解锁；星只升不降；阈值来自 config.json（`course.test.js`）。
9. 课内练习：每符号干净答对 2 次；答错隔 2 个再出现；提示后答对不算干净（`course.test.js`）。
10. 存档原子写入；损坏文件备份为 `.corrupt`；清除进度保留设置（`store.test.js`、`progress.test.js`、`--e2e` 冒烟）。
11. M3 配色：surface 非纯白/纯黑；4 个种子 × 浅/深色下正文 ≥ 4.5:1、控件 ≥ 3:1（`palette.test.js`、`docs/contrast.md`）。
12. `prefers-reduced-motion: reduce` 下所有动效瞬时完成；无水波、抖动、闪烁、循环动画。
13. 所有控件有可见焦点环与可读名称，点击区 ≥ 44 px。
14. 每个页面在浅色/深色 × 720×960/480×640，以及陶土种子（720×960 浅/深）的截图在 `docs/shots/`，且无明显缺陷。
15. 测试与截图不读写真实 userData。
